📖 Пошаговая инструкция по настройке Supabase (2 минуты)
  1. Создайте проект на supabase.com (бесплатный тариф).
  2. Перейдите во вкладку SQL Editor слева, нажмите New query, вставьте SQL-скрипт ниже и нажмите Run:
    SQL-скрипт создания таблицы photos и правил доступа
  3. Перейдите в раздел Storage слева:
    • Нажмите New bucket.
    • Введите имя photos.
    • Включите переключатель Public bucket (обязательно, чтобы фото отображались на сайте).
    • Нажмите Save bucket.
  4. Перейдите в Project Settings → API: скопируйте Project URL и anon public ключ, вставьте их в поля выше и нажмите «Сохранить и проверить».
💡 Подсказка: чтобы настройки применялись для всех пользователей сразу из кода без ввода ключей в браузере, вы также можете указать Project URL и Anon Key в файле supabase.js.
